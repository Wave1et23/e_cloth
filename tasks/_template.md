# 任务模板

> 进行中 / 待开始的任务只放在 `tasks/`；完成后把结论写进 `docs/ITERATION_LOG.md`，本文件不再保留“已完成进度”。
> 无法从代码、文档或用户输入确定的原因，一律写「待补充」，不要编造。

- **状态**：待开始 / 进行中 / 阻塞
- **版本**：目标版本（未定就写「未定」）
- **类型**：feature / bug / docs / deploy / verification
- **对应 task**：闸门编号或任务 id（如 `G2`、`tasks/002-...`）
- **改了什么**：实际改动；尚未执行就写「尚未执行」
- **为什么**：动机与约束；无法确定写「待补充」
- **怎么验证的**：命令、HTTP、页面、真机步骤；未验证写「待验证」
- **影响哪些文档**：需要同步的文档路径
- **已知限制**：当前明确做不到/未覆盖的事
